토니 파일박스 설치·사용 가이드

맥의 파일·용량·중복·캐시를 한눈에 보고, 추천대로 안전하게 정리하는 대시보드예요. 모든 정리는 휴지통 이동이나 폴더 이동이라 되돌릴 수 있고, 파일 정보는 이 맥 밖으로 나가지 않아요.

Mac용 무료 다운로드 설치부터 보기

필요한 것: Apple Silicon 맥(M1 이상) · macOS 13 Ventura 이상 · Google Chrome 권장(없으면 Safari로 열려요)

설치하기

  1. 위의 [Mac용 무료 다운로드] 버튼을 누르면 설치 파일 TonyFileBox-Setup.pkg가 다운로드 폴더에 저장돼요.
  2. 설치 파일 「TonyFileBox-Setup.pkg」를 두 번 누릅니다.
  3. "열 수 없음" 또는 "확인할 수 없습니다" 창이 뜨면 [완료]를 누릅니다. Apple 개발자 인증을 받지 않은 개인용 앱이라 처음 한 번만 뜨는 창이에요.
  4. 화면 왼쪽 위 Apple 메뉴 → 시스템 설정… → 개인정보 보호 및 보안 → 맨 아래 보안 부분의 설치 파일 옆 [그래도 열기]를 누릅니다.
  5. 확인창에서 [그래도 열기]를 누르고 맥 암호(또는 Touch ID)를 입력합니다.
  6. 설치 프로그램에서 [계속] → [설치]를 누르고 맥 암호를 입력한 뒤 [닫기]를 누릅니다. 응용 프로그램 폴더에 토니 파일박스가 설치돼요.

처음 실행하기

  1. Finder → 응용 프로그램 → 토니 파일박스를 두 번 누릅니다.
  2. 대시보드 창이 열리고 처음 한 번 디스크 전체를 스캔해요(1~2분). 위쪽 줄에 진행 상황이 보여요.
  3. 화면 맨 위 메뉴바에 박스 아이콘과 맥 건강 점수가 나타나요. 알림 허용을 물으면 [허용]을 누르세요.
  4. Dock에 두려면 응용 프로그램 폴더의 토니 파일박스를 Dock으로 끌어다 놓으세요.

전체 디스크 접근 권한

메일·메시지·사진·일부 라이브러리 폴더는 macOS가 보호합니다. 권한을 켜야 그 폴더들의 용량까지 정확히 셀 수 있어요. 권한이 없어도 나머지 기능은 모두 동작합니다.

  1. 화면 왼쪽 위 Apple 메뉴 → 시스템 설정… → 왼쪽 목록 개인정보 보호 및 보안 → 오른쪽 전체 디스크 접근 권한을 엽니다. 앱 안 가이드의 시스템 설정 열기 버튼으로도 바로 열 수 있어요.
  2. 목록에서 토니 파일박스를 찾아 스위치를 켭니다.
  3. 목록에 없으면 아래쪽 ＋ 버튼 → 응용 프로그램 › 토니 파일박스을 선택하고 열기를 누른 뒤 스위치를 켭니다.
  4. Mac 로그인 암호(또는 Touch ID)를 묻으면 입력합니다.
  5. "종료 후 다시 열기"가 나오면 누르고, Dock에서 토니 파일박스를 다시 연 뒤 왼쪽 아래 ⟳ 로 다시 스캔합니다.

화면별 사용법

개요

맥 건강 점수와 감점 이유, 총 사용량, 위치별 용량, 드라이브, 정리 후보를 한 화면에 보여 줘요. 맨 위 [추천대로 정리하기] 한 번으로 안전한 정리를 끝낼 수 있어요.

추천

정리 추천을 카드로 보여 줘요. 카드마다 이유·확보 용량·안전도가 있고, 켜고 끄거나 펼쳐서 항목을 하나씩 뺄 수 있어요. 안전 카드는 처음부터 켜져 있고 확인 필요 카드는 직접 켜야 해요.

검색

개요 맨 위 큰 검색창이나 검색 화면에 이름 일부·떠오르는 말·날짜를 섞어 넣으면 찾아요(예: 어제 받은 pdf, 영수증 9월). 날짜와 종류는 조건으로 알아듣고, 영수증 → receipt처럼 연상되는 말도 함께 찾아요. 내용까지로 바꾸면 문서 속 글자도 찾아요. 개요 화면에서 / 키를 누르면 바로 입력할 수 있어요.

탐색

데스크탑·문서·다운로드 같은 섹션을 폴더 아이콘으로 보고, 이름·수정일·크기·종류순으로 정렬해요. 두 번 누르면 폴더로 들어가거나 미리보기가 열려요. iCloud에만 있는 파일은 파란 구름으로 표시돼요.

저장공간

어떤 폴더가 공간을 많이 쓰는지 폴더 지도로 보여 줘요. 칸을 누르면 그 폴더 안으로 들어가요.

정리

완전히 같은 중복 파일, 이름만 다른 버전 묶음, 비슷한 사진, 비슷한 영상을 찾아 남길 것을 추천해요. 유형별 칩으로 이미지·영상·문서만 따로 볼 수 있어요.

활성/비활성

파일을 마지막으로 쓴 때에 따라 활성·보통·비활성·보관 후보로 나눠요. 오래 안 쓴 큰 파일은 외장 드라이브에 보관할 수 있어요.

시스템

CPU·메모리·디스크·배터리·발열과 자원을 많이 쓰는 프로세스, 자동 실행 항목을 보여 줘요.

작업 기록

정리한 모든 작업이 남아요. 항목마다 [되돌리기]가 있고, 한 번에 정리한 묶음은 [전부 되돌리기]로 한 번에 돌려요.

정리와 되돌리기

  • 정리는 모두 휴지통 이동, 폴더 이동, 외장 드라이브 보관 중 하나예요. 영구 삭제는 하지 않아요.
  • 실제 공간은 휴지통을 비울 때 생겨요. 휴지통 비우기는 확인하신 뒤 Finder에서 직접 해 주세요.
  • 시스템 폴더, 앱 내부, 사진 보관함, Time Machine 백업 디스크는 보호돼서 건드리지 않아요.
  • Time Machine 로컬 스냅샷이 있으면 지운 공간이 조금 늦게 돌아올 수 있어요. macOS가 스냅샷을 지우면 돌아와요.

메뉴바와 자동 스캔

  • 메뉴바의 박스 아이콘 옆 숫자는 맥 건강 점수예요. 누르면 정리 추천, 디스크 여유, 휴지통, 마지막 스캔을 볼 수 있어요.
  • 자동 스캔에서 매일·매주·끄기를 고를 수 있어요(기본 매주). 자동 스캔 뒤 정리할 게 5GB 넘게 쌓이면 알림을 보내요.
  • 로그인할 때 자동 실행을 켜 두면 맥을 켤 때 메뉴바와 엔진이 창 없이 조용히 시작돼요.
  • 위험 알림을 켜 두면 메모리·CPU 과부하, 발열, 디스크 부족 같은 빨간 상태가 이어질 때 알림을 보내고, 풀리면 다시 알려 줘요. 알림을 누르면 시스템 화면이 열려요.

언어 바꾸기

위쪽의 지구본 버튼을 누르고 언어를 고르면 화면, 추천 카드, 알림, 메뉴바가 모두 그 언어로 바뀌어요.

이 안내 페이지도 아래에서 원하는 언어로 바로 볼 수 있어요.

지우기

  1. 메뉴바 박스 아이콘 → 로그인할 때 자동 실행이 켜져 있으면 끄고 [메뉴바에서 끄기]를 누릅니다.
  2. 응용 프로그램 폴더의 토니 파일박스를 휴지통으로 옮깁니다.
  3. 데이터까지 지우려면 Finder → 이동 → 폴더로 이동…에 ~/Library/Application Support/TonyFileBox를 넣고 그 폴더를 휴지통으로 옮깁니다.

문제가 생기면

  • 창이 안 열리거나 화면이 비어 있으면 Dock에서 토니 파일박스를 다시 열어 보세요.
  • 숫자가 이상하면 왼쪽 아래 ⟳ 버튼으로 다시 스캔하세요.
  • 영상 미리보기와 비슷한 영상 찾기는 ffmpeg가 있어야 켜져요. Homebrew를 쓰신다면 터미널에서 brew install ffmpeg를 실행하세요.
  • 그래도 안 되면 아래 기록 파일 두 개를 보내 주세요.

~/Library/Logs/TonyFileBox-launcher.log~/Library/Application Support/TonyFileBox/server.log

지금, 무료로 시작하세요.
